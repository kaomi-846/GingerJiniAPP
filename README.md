# 🫚 ジニちゃん 生姜畑のひだまりルーム

ぽかぽかした生姜畑の部屋で、Jiniちゃんをお世話したりミニゲームで遊んだりできるブラウザ育成アプリです🌱💛  
忙しい日常の中でも、いつでもJiniちゃんが笑顔で迎えてくれます。

---

## ✨ 主な特徴・スタイル

- **4つのステータス**: おなか・きれい・ごきげん・なかよし度を見守りながら、ジニちゃんと仲良くなろう！
- **なかよし度レベルアップ**: ジニちゃんをなでたり、お世話やミニゲームで遊ぶと経験値（⭐）が貯まり、レベルが上がるとご褒美コインがもらえます🎉
- **スケジュール連動の吹き出し**: 上部の「📅」ボタンから予定をメモすると、ジニちゃんが今日の予定を可愛くおしらせしてくれます♪
- **ハッピーキャンディフェス（イベント）**: 下部のイベント枠をタップすると、毎日1回デイリーフェスボーナス（🪙 100 G）が受け取れます🍬✨
- **楽しいお世話＆ミニゲーム**: ごはん、おふろ、お着替え（きせかえ）、なかま図鑑、ミニゲーム（お菓子キャッチ・生姜畑のお散歩）が盛りだくさん！
- **ショップでお買い物**: コインを使って、美味しいごはんや可愛いアクセサリーをゲットしよう！
- **いつでもどこでも**: ブラウザを開くだけで、すぐにJiniちゃんに会えます。

---

## 📱 遊び方

1. **お世話をする**: 画面下のボタン（ごはん、おふろ、あそぶ、きせかえ、ずかん、ショップ）やジニちゃんをタップしてお世話します。
2. **ミニゲームでコインを稼ぐ**: 「あそぶ」のミニゲームやイベントでコインを貯め、ショップでお買い物や着せかえを楽しみましょう。
3. **予定をおぼえてもらう**: 右上のカレンダーボタン（📅）から大切な予定を登録すると、ジニちゃんが応援してくれます。

---

- このアプリは個人で制作したWebブラウザ向けの育成ゲームです。
- プレイデータ（ゲームの進行状況やスケジュールなど）はお使いのブラウザの内部（ローカルストレージ）に自動保存されます。
- 予告なしに仕様変更やアップデートを行う場合があります。
