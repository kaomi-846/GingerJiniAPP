# 🫚 Jiniちゃん 生姜畑のひだまりルーム

たまごっち風の、放置しても絶対に死なない優しい世界観のブラウザ育成Webアプリです💛  
高知県の生姜畑をモチーフに、Jiniちゃんや仲間たちとのんびり触れ合えます。

## ✨ 特徴
- **4つのステータス**: おなか、ごきげん、きれい、なつき（またはエネルギー）をバランスよくお世話しよう！
- **豊富なごはん・アイテム**: 生姜湯やクッキー、いちごの帽子などのおしゃれアイテムがいっぱい！
- **仲間たちとの出会い**: 芽ぐみちゃんなどが遊びに来ておしゃべりできるよ。
- **ミニゲーム**: タップしてコインを稼いでお買い物を楽しもう！

## 📱 遊び方
1. 画面のボタン（ごはん、おそうじ、ショップ、あそぶ、おふろ、ねる等）を押してJiniちゃんをお世話します。
2. お世話をしたりミニゲームで遊ぶと「生姜コイン」が貯まります。
3. 貯まったコインでショップからアイテムを買うことができます。

## 🛠️ 使用技術
- HTML5 / CSS3 (Tailwind CSS)
- JavaScript (Vanilla JS)
- LocalStorage（データ自動保存）
