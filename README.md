# 🫚 Jiniちゃん 生姜畑のひだまりルーム

ぽかぽかした生姜畑のルームで、Jiniちゃんをお世話したりミニゲームで遊んだりできるブラウザアプリです🌱💛  
忙しい日常の中でも、いつでもJiniちゃんが笑顔で迎えてくれます。

## ✨ 特徴
- **4つのステータス**: おなか・ごきげん・きれい・なつきを見守りながら、Jiniちゃんと仲良くなろう！
- **楽しいお世話アクション**: ごはん、たんけん、ショップ、あそぶ、おふろ、ねるの6つのボタンで毎日のお世話ができるよ。
- **ショップでお買い物**: コインを貯めて、可愛いアイテムを手に入れよう！
- **いつでもどこでも**: ブラウザから開くだけで、すぐにJiniちゃんに会いにいけます。

## 📱 遊び方
1. 画面下のボタン（ごはん、たんけん、ショップ、あそぶ、おふろ、ねる）をタップしてJiniちゃんをお世話します。
2. たんけんやミニゲーム（あそぶ）でコインを貯めると、ショップでお買い物が楽しめます。
3. Jiniちゃんをタップすると、なつき度やごきげんがアップします💛
